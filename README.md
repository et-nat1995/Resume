# Tamir Natanov — Portfolio

Personal portfolio for [et-nat.com](https://et-nat.com), built with React, Next.js-compatible routing through Vinext, TypeScript, and the Sites runtime.

## Development

- `npm run dev` starts the local development server.
- `npm run build` creates the deployable production bundle.

The site is a single responsive narrative page with interactive engineering and case-study views. Content is intentionally limited to public professional information and high-level, non-confidential descriptions of engineering work.
